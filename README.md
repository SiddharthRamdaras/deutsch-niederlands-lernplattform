# Deutsch Lernstudio

Een overzichtelijke studie-site voor Duits-Nederlands met:

- Flashcards met woord + lidwoord + betekenis
- Korte grammatica-uitleg
- Oefenquizzen
- Woordenlijst met zoekfunctie
- Studieplan voor 3 dagen
- Extra handige tips om sneller te leren

## Hoe je het opent

Open gewoon `index.html` in je browser.

Als je een lokale server wilt, kun je ook dit draaien in de terminal:

```bash
python -m http.server 8000
```

Ga daarna naar:

```text
http://localhost:8000
```

## Inhoud van de app

- Overzicht / leerplan
- Flashcards voor vocabulaire
- Grammatica overzicht
- Quiz-oefeningen
- Zoekbare woordenschat

## Doel

Deze app is gemaakt voor een korte, intensieve leerperiode van 3 dagen, zodat je de basis snel en overzichtelijk kunt oefenen.
